# 接口文档

后端启动后可访问 Swagger 在线文档：`http://localhost:3000/api/docs`（可直接调试）。本文档汇总全部接口及约定。

## 1. 约定

- 接口前缀：`/api`
- 认证：除注册、登录外，所有接口需在请求头携带 `Authorization: Bearer <token>`
- 请求体：`application/json`（上传头像为 `multipart/form-data`）
- 日期：生日相关日期为 `YYYY-MM-DD` 字符串（北京时间）；时间戳为 ISO 8601
- 分页参数：`page`（默认 1）、`pageSize`（默认 20，最大 100）；分页结果为 `{ items, total, page, pageSize }`
- 修改类接口中，字段不传表示不修改，传 `null` 或空字符串表示清空

### 1.1 统一响应

成功：

```json
{ "code": 0, "message": "success", "data": { } }
```

失败时 HTTP 状态码与 `code` 相同，`message` 为中文提示：

```json
{ "code": 400, "message": "手机号格式不正确", "data": null }
```

| 状态码 | 含义 |
|---|---|
| 400 | 参数校验失败（如格式错误、生日不存在） |
| 401 | 未登录，或登录已失效（被禁用、密码已修改、token 过期） |
| 403 | 权限不足；账号待审核 / 已禁用（登录时）；需先修改初始密码 |
| 404 | 数据不存在 |
| 409 | 学号或账号已存在 |
| 413 | 上传文件超过 2MB |
| 429 | 操作太频繁（登录、注册每 IP 每分钟 10 次） |

### 1.2 主要数据结构

**Birthday（生日输入）**

| 字段 | 类型 | 说明 |
|---|---|---|
| calendar | `SOLAR` \| `LUNAR` | 公历 / 农历 |
| year | number \| null | 出生年份，不填则不显示年龄 |
| month | number | 1~12（农历为农历月） |
| day | number | 公历 1~31，农历 1~30 |
| isLeapMonth | boolean | 农历闰月出生 |

返回时额外包含 `text`，如 `"农历2025年闰六月初三"`、`"2004年5月12日"`。

**DirectoryUser（通讯录条目）**

```json
{
  "id": 3,
  "name": "王芳",
  "studentNo": "2022010102",
  "avatar": "/uploads/avatars/8c0f...png",
  "group": { "id": 2, "name": "第二组" },
  "role": "STUDENT",
  "phone": "13800138001",
  "qq": "100137",
  "email": "2022010102@example.com",
  "dorm": "2号楼 302",
  "remark": null,
  "birthday": { "calendar": "SOLAR", "year": 2004, "month": 10, "day": 28, "isLeapMonth": false, "text": "2004年10月28日" }
}
```

**Profile（本人 / 管理员可见）**：在 DirectoryUser 基础上增加 `username`、`status`、`mustChangePassword`、`emailNotify`、`lastLoginAt`、`createdAt`。

**BirthdayEntry（生日列表条目）**

```json
{
  "user": { "id": 4, "name": "张伟", "studentNo": "2022010103", "avatar": null, "group": { "id": 3, "name": "第三组" } },
  "calendar": "LUNAR",
  "birthdayText": "农历2003年九月廿一",
  "date": "2026-10-30",
  "daysLeft": 3,
  "age": 23
}
```

`date` 为本次生日对应的公历日期，`daysLeft` 为距今天数（0 表示今天），`age` 为本次过几岁生日（未填出生年份为 null）。

## 2. 认证

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /auth/register | 学生注册，注册后为待审核状态 |
| POST | /auth/login | 登录 |
| GET | /auth/me | 当前用户信息（Profile） |
| PUT | /auth/password | 修改密码 |

**POST /auth/register**

```json
{ "studentNo": "2022010150", "name": "张三", "password": "abc123", "phone": "13800138000" }
```

- 学号 4~20 位数字，同时作为登录账号；姓名 2~20 个中文或英文字符；密码 6~32 位且包含字母和数字；手机号选填
- 成功：`{ "message": "注册成功，请等待管理员审核" }`；学号已注册：409

**POST /auth/login**

```json
{ "username": "2022010101", "password": "Student123" }
```

成功返回 `{ "token": "eyJ...", "user": Profile }`。账号或密码错误：401；待审核 / 已禁用：403。

**PUT /auth/password**

```json
{ "oldPassword": "Student123", "newPassword": "New12345" }
```

成功返回 `{ "token", "user" }`。修改后旧 token 全部失效，客户端应改用返回的新 token。需要修改初始密码的用户也可以调用本接口和 `/auth/me`，其余接口返回 403"请先修改初始密码"。

## 3. 个人信息与通讯录

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /profile | 本人资料（Profile） |
| PUT | /profile | 修改本人资料 |
| POST | /profile/avatar | 上传头像，表单字段 `file`；JPG / PNG / WEBP，≤ 2MB |
| GET | /users | 通讯录，参数 `keyword`（姓名或学号模糊匹配）、`groupId`、`page`、`pageSize` |
| GET | /users/:id | 同学详情（DirectoryUser） |

**PUT /profile**（学生不能修改姓名、学号、小组）

```json
{
  "phone": "13800138000",
  "qq": "",
  "email": "me@example.com",
  "dorm": "3号楼 402",
  "remark": "爱好篮球",
  "birthday": { "calendar": "LUNAR", "year": 2004, "month": 8, "day": 15, "isLeapMonth": false },
  "emailNotify": true
}
```

`qq: ""` 表示清空 QQ；`birthday: null` 表示清除生日。生日会按历法和出生年份校验是否真实存在，例如农历 2024 年没有闰六月、农历 2026 年二月只有 29 天，均返回 400。

**POST /profile/avatar** 返回 `{ "avatar": "/uploads/avatars/<uuid>.png" }`，旧头像文件会被删除。

通讯录只返回状态为"正常"的账号，管理员排在最前，其余按学号排序。

## 4. 生日

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /birthdays/today | 今天过生日的同学 |
| GET | /birthdays/upcoming?days=7 | 未来 N 天（含今天，1~60）过生日的同学 |
| GET | /birthdays/month?year=2026&month=10 | 某月过生日的同学，默认本月 |

均返回按日期排序的 BirthdayEntry 数组。农历生日按当年对应的公历日期参与计算，例如查询 2026 年 9 月会包含"农历八月十五"（2026-09-25）。

## 5. 公告、分组、通知

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /announcements | 公告列表，置顶优先、按时间倒序，分页 |
| GET | /announcements/:id | 公告详情 |
| GET | /groups | 小组列表，含 `memberCount`（正常账号数） |
| GET | /notifications | 我的通知，参数 `unreadOnly=true` 只看未读，分页 |
| GET | /notifications/unread-count | `{ "count": 3 }` |
| PUT | /notifications/:id/read | 标记已读（只能操作自己的通知） |
| PUT | /notifications/read-all | 全部标记已读，返回 `{ "count": 标记数量 }` |

通知条目：

```json
{
  "id": 21,
  "type": "BIRTHDAY_TODAY",
  "title": "今天是 李明 的生日",
  "content": "今天是 李明 的生日，别忘了送上祝福~",
  "relatedId": 2,
  "refDate": "2026-10-27",
  "readAt": null,
  "createdAt": "2026-10-27T00:00:00.123Z"
}
```

`type`：`BIRTHDAY_TODAY` 当天生日、`BIRTHDAY_UPCOMING` 提前提醒、`ANNOUNCEMENT` 新公告（`relatedId` 为公告 id）。

## 6. 管理员接口（需 ADMIN 角色）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /admin/stats | `{ total, active, pending, disabled, missingBirthday }` |
| GET | /admin/users | 用户列表，参数 `status`、`role`、`groupId`、`keyword`（姓名 / 学号 / 账号）、分页；返回 Profile |
| POST | /admin/users | 新增账号 |
| PUT | /admin/users/:id | 编辑学生信息 |
| PATCH | /admin/users/:id/status | `{ "status": "ACTIVE" \| "DISABLED" }`：审核通过、启用、禁用 |
| POST | /admin/users/:id/reset-password | `{ "password": "Init1234" }` |
| DELETE | /admin/users/:id | 删除学生（也用于驳回注册） |
| POST / PUT / DELETE | /admin/groups[/:id] | 小组增删改，`{ "name": "第一组", "sort": 1 }` |
| POST / PUT / DELETE | /admin/announcements[/:id] | 公告增删改，`{ "title", "content", "pinned" }`；发布时通知全班（不含发布者） |
| GET | /admin/birthdays | `{ today, entries: BirthdayEntry[], missing: UserBrief[] }`，entries 按下次生日排序 |
| GET | /admin/export/directory | 下载 Excel，文件名 `班级通讯录-YYYY-MM-DD.xlsx` |
| POST | /admin/reminders/run | `{ "date"?: "YYYY-MM-DD" }`，立即执行生日提醒 |

**POST /admin/users**

```json
{
  "name": "王老师",
  "username": "teacher",
  "studentNo": null,
  "role": "ADMIN",
  "password": "Init1234",
  "groupId": null,
  "phone": "13900139000",
  "birthday": { "calendar": "SOLAR", "year": null, "month": 3, "day": 8, "isLeapMonth": false }
}
```

- 学生账号必须填写学号；`username` 不填则使用学号
- 新账号直接为正常状态，首次登录必须修改密码

**PUT /admin/users/:id**：可修改学生可改的全部字段，以及 `name`、`studentNo`、`groupId`、`role`。修改学号时，若该用户的登录账号原本等于学号，会同步修改登录账号。

**限制**：管理员不能禁用、删除自己，不能修改自己的角色（403）。禁用、重置密码会让该用户已登录的会话立即失效。

**POST /admin/reminders/run** 返回：

```json
{ "date": "2026-10-27", "birthdayToday": 1, "birthdayUpcoming": 1, "created": 25, "emailed": 0 }
```

`created` 为本次新生成的通知数，已生成过的不会重复生成。
